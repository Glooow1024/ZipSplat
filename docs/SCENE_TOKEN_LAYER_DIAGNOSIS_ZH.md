# Scene token 逐层诊断

日期：2026-09-08；分支 `dev/scene_token`。本次仅推理诊断，优化器更新 0 次，未修改模型结构、参数或数据。

结论：**趋同从 DA3 编码阶段开始；第一个 block 先出现公共分量占优，随后 MLP 与深层传播使去均值能量集中在少数方向。不能归因于所有槽位初始化相同，也不能只怪解码器。** 原版 patch 与新增 scene slot 的行为明显不同，但“高余弦”“低有效秩”各自都不是重建失败的充分判据。

## 1. 执行范围与核验

四组模型：重放初始化参照、v3 checkpoint_100、v3 checkpoint_200、原 released ZipSplat。原版保留率 `256/324`，与新模型同 K/G；原版几何 KV 仍保留全部 patch，这不是完全相同的信息预算。

252px、BF16、NoPrior、GT 相对相机和 context 深度尺度，无相机配准/TTO；与初测口径一致。检查完整 40 个 DA3 block 的输入、注意力残差后、MLP 残差后；另检查保留的 patch、三组 local/global 归一化/投影、三轮 CA/SA、颜色 query/CA、head 输入。

- 原始 forward 全部保留；hooks 只读，方法 wrapper 委托原方法后记录返回值。每个模型/样本均先执行无 hook 前向，再恢复 RNG 执行有 hook 前向。

- 100/200 步模型严格加载 v3 checkpoint。此前训练冻结了已有 DA3 权重，只训练新增槽位/颜色 query 与已有下游模块；不能把本轮结果描述成 DA3 已联合微调之后的结果。

## 2. 指标怎样读

每个视角分别对 256 个 scene slot 统计，再对视角等权平均；原版 DA3 对每视角 324 个 patch 统计。另保存 V2 全部 token pooled 指标。V6 scene 特征保存完整逐视角秩，不对 1536 个槽位做抽样秩估计。

- 余弦：不同 token 的平均非对角 cosine；公共特征很强也会使其接近 1。
- 相对差异：`||X-mean_token(X)||F / ||X||F`，区分独立变化与公共分量。
- 有效秩：去 token 均值后，平方奇异值归一为 p，计算 `exp(-sum(p log p))`。使用禁用 autocast 的 FP64 Gram 特征值计算。
- 同时保存去均值 RMS、总 RMS、前 1/5 个方向能量占比、残差增量/输入范数，避免把相对差异下降误说成绝对差异消失。

**有效秩 5 不等于仅有 5 个有用 token，更不等于场景容量就是 5。** 它衡量能量分布，不是数学秩、信息量或几何覆盖；随机噪声也可以有很高的秩。原版末层 patch 的有效秩本身也不高，不能设一个统一通过阈值。

## 3. 200 步模型：问题在哪里出现

书架训练样本，以下全部是**每视角内统计的均值**：

| 位置 | 平均 cosine | 去均值有效秩 | 相对差异 |
|---|---:|---:|---:|
| 学得的初始化参数 / 进入 block0 | 0.0049 | 231.21 | 99.56% |
| block0 注意力残差后 | 0.9564 | 217.85 | 20.89% |
| block0 MLP 残差后 | 0.9833 | 28.28 | 15.27% |
| block1 输出 | 0.9782 | 11.97 | 18.60% |
| block12 输出，第一次全局注意力之前 | 0.9463 | 5.15 | 25.36% |
| block19 输出 | 0.9140 | 4.20 | 29.62% |
| block29 输出 | 0.9759 | 4.68 | 15.40% |
| block39 输出 | 0.9879 | 4.92 | 10.94% |
| 最深层 prepare 完成 | 0.9920 | 3.29 | 8.89% |
| 三轮几何融合完成 | 0.9524 | 1.735 | 28.57% |
| 颜色分支最终输出 | 0.9965 | 1.436 | 6.04% |

### 3.1 第一个注意力：共同更新淹没相对差异

不是同值初始化：200 步参数平均 cosine 仍只有 0.0049，有效秩 231.21；重放随机初始化分别为 -0.00005、234.77。不同槽位的向量显著不同，同一槽位在不同视角共享初始化。

block0 注意力的增量范数约为槽位输入的 **4.77 倍**；原版 patch 对照只有 **0.478 倍**。初始 scene RMS 约 0.0203，原版图像 patch embedding RMS 约 0.2649，二者尺度与内容来源差异显著。

注意力之后，scene 总 RMS 从 0.0203 增至 0.0990，但去均值 RMS 从 0.02023 增至 0.02068，**没有消失**。因此这里的 cosine 跃升主要说明公共分量迅速占优，不能称为所有槽位已经相同。

这是“初始化幅度/内容与预训练层不匹配”的证据线索，尚未通过单因素干预证明因果。直接放大随机向量可以改善某些多样性指标，却不保证增加图像信息或改善重建。

### 3.2 第一个 MLP：少数变化方向被放大

block0 MLP 后，去均值 RMS 从 0.02068 增至 0.02935，而第一主方向能量占比从 **4.23% 增至 50.96%**，有效秩从 217.85 降至 28.28。这更符合“变化能量集中到少数方向”，不是全部变化被抹掉。

block12 输出第一方向已占约 75.45%，有效秩 5.15。**此时尚未进行第一次跨视角全局注意力**，所以不能将问题起点归于全局 attention 混合了不同视角。

训练进程也有区别：重放初始化在 block0 MLP 后有效秩 193.69，100步为122.20，200步为28.28；参数矩阵本身的有效秩分别为234.77、234.05、231.21。说明变化主要在参数经过冻结的非线性网络之后显现，不能只检查参数矩阵判断是否分化。

但重放初始化到 block19 也已降至3.41、末层3.86；200步末层4.92。不能据早层秩下降就概括为“训练把所有层都越训越坏”，实际 loss 与部分差异幅度有所改善，最终仍缺少有效分工。

### 3.3 深层与特征接口继续放大公共分量

block24–29 附近 cosine 再次升高，多个注意力残差扩大公共分量。200步末层相对差异仅10.94%。最深层 prepare 后进一步变为8.89%，其 global pre_norm 分支只有5.68%；接口没有把已有独立变化有效恢复出来。

原版训练样本 patch 在 block19 有效秩108.59、相对差异77.40%；末层为8.51、46.24%。新模型保留的 patch 末层为10.44、44.61%，整体曲线仍接近原版。**新增槽位的异常明显强于同一网络中的 patch**，不是整张图的所有表征一同变成常量；但这并不证明增加槽位对原 patch 完全无影响。

## 4. 解码器和颜色分支怎样理解

几何融合没有普遍降低相对差异：书架样本从prepare的8.89%增至28.57%，cosine反而下降。不过每视角有效秩最终只有1.735，说明变化仍集中在很少的方向，不能把它当成足够丰富的几何表示。

与之前报告口径一致，将两个视角的512个槽位合并后，200步几何特征为 cosine **0.9391**、有效秩 **2.4926**、相对差异 **30.72%**。原版同512 query为0.4167、17.443、78.27%。每视角的1.735与pooled的2.4926是不同统计，不是结果冲突。

颜色 query 投影后，相对差异为18.99%；完整颜色CA后仅6.04%，cosine从0.9751增到0.9965。但绝对去均值 RMS 是0.07761→0.07654，基本保留；主要变化是加入强公共分量，总 RMS 0.4086→1.2670。

还需修正一种容易误判的解释：**颜色 attention 图相似，本身不足以指向新模型缺陷。** 书架场景新模型颜色 query 注意力分布的平均相似度约0.99965，原版约0.99999，原版同样高度相似。原版通过颜色 patch query 的残差路径保留局部内容；新路径的 query 来自已趋同的几何特征，其残差中的内容和尺度都需要重新适配。该机制解释与当前观测相符，但还没有做分支替换来确定因果贡献。

attention 统计复用实际投影、QK norm、RoPE，再用FP32重算softmax，未替换模型的SDPA。DA3取首视角全部query；新模型融合/颜色取首视角256query；原版融合/颜色取k-means顺序的前324query，**不对应一个视角**。原版/新模型这组颜色数值用于反驳“相似attention只发生在新模型”，不能视为严格逐query配对指标。

## 5. 验证样本复核与结论边界

固定验证场景6视角也出现同一路径：200步 block0 MLP后有效秩28.46，block12为4.93，末层4.60；几何融合后每视角2.50、相对差异22.80%；颜色输出相对差异4.08%。因此现象不只出现在那一个被拟合的书架输入，但两场景仍不足以作全数据泛化结论，场景和视角数的影响也没有在本轮分离。

已支持：

1. 相同数值初始化不是原因；共享跨视角初始化也不能解释每视角内的结果。
2. 第一个局部注意力即出现共同分量占优；明显能量集中在MLP/深层继续发展，早于全局attention和解码器。
3. 仅增加颜色attention多样性损失，或仅改后端decoder，缺少针对上游问题的依据。
4. 现在没有证据说明S256本身不够；把S加大不是由本轮诊断直接支持的修复。

尚未证明：初始化尺度、缺少空间锚点、冻结主干、槽位互相注意、训练不足，各自贡献多大；也未证明这个方向不可行。

## 6. 下一步开发顺序（尚未执行）

先针对同一固定样本做单因素对照，同时观察重建细节、几何覆盖与上述层级指标，不能以提高随机噪声的秩作为成功。

1. **优先检查槽位输入与预训练主干的适配。** 单独比较初始化幅度；再独立比较带图像内容/空间锚点的槽位构造。二者不要同轮一起改，且后者属于结构方案变更。
2. **调整DA3适配范围的对照应覆盖早层。** 当前主干已有权重冻结；只解冻后几层不能直接适配第一个attention/MLP。可以在同预算的小样本训练里比较冻结、后部解冻、包含早部的受限适配。这里是待验证方向，不承诺哪种必然有效。
3. 上游分工改善后，再单独评估颜色query/残差幅度与信息来源。原版颜色attention高度共享，故不先把“attention必须不同”写成硬目标。
4. 固定样本细节恢复前，继续保持S256，不扩大数据或启动全量长训练。必要时再做输入尺度/位置/注意力路由的进一步因果干预。

本次完成逐层定位，P3高质量拟合仍未通过；未自动执行以上训练或结构变更。
